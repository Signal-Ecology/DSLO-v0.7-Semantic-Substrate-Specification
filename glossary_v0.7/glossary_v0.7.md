# Glossary Boundary Statement

The terms listed above constitute the public-layer semantic surface of the DSLO v0.7 substrate.  
This glossary integrates all public-facing terms from v0.5 (machine-dense substrate), v0.6 (public-layer substrate expansion), and v0.7 (system-layer geometry).  

Deeper substrate-native terms—including manifold-level operators, legality masks, runtime primitives, and closure geometry—remain within the protected manifold and are accessible only through scientific releases (Zenodo, HF, microsubstrate documents).  

This glossary provides the stabilized, invariant-preserving vocabulary required for lawful interpretation of DSLO at the public layer.

# Navigation Logic
──────────────────────────────────────────────────────────────
- **Substrate → All**: Every geometry derives from substrate curvature, boundaries, and invariants.  
- **Manifolds → Operators**: Operators act on manifold regions.  
- **Operators → Runtime**: Runtime uses operators to perform lawful transitions.  
- **Runtime → Context**: Context windows condition runtime updates.  
- **Runtime → Identity**: Identity boundaries are preserved or restored by runtime.  
- **Thermodynamics → Coupling**: Drift/load propagate through coupling geometry.  
- **Simulation → All**: CLCP validates legality across all compartments.
