# Internet Routing Geometry — Summary (DSLO v0.7)

Internet routing is a distributed geometry where routers select paths based on
BGP announcements, link‑state propagation, latency, congestion, and policy
constraints. The global topology emerges from local decisions.

**Key Properties**
- Propagation‑driven routing  
- AS‑policy curvature  
- Congestion gradients  
- Multi‑layer protocol coherence  

**DSLO Interpretation**
- Operators: propagation, routing, distributed cognition  
- Invariants: propagation coherence, policy stability  
- Manifolds: AS‑topology, propagation, routing‑graph  
- Dynamics: drift, collapse/restoration
