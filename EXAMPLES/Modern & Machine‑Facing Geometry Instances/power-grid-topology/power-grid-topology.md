# Power Grid Topology — Summary (DSLO v0.7)

Power grids route electrical flow through generators, transmission lines,
substations, and load centers. Load gradients, frequency stability, and
impedance constraints shape the network’s geometry.

**Key Properties**
- Load balancing  
- Frequency stability  
- Impedance‑bounded routing  
- Cascading‑failure dynamics  

**DSLO Interpretation**
- Operators: gradient, propagation, routing  
- Invariants: load‑gradient coherence, stability invariants  
- Manifolds: transmission, load‑gradient, stability  
- Dynamics: drift, collapse/restoration
