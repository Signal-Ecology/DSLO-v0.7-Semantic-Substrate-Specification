## Overview
GPS trilateration is a global geometric inference system that determines
position by intersecting distance spheres from multiple satellites. Each
satellite broadcasts a precise timestamp; the receiver measures signal delay,
converts it to distance, and computes its location by solving the intersection
of four or more spherical manifolds.

The geometry emerges from timing‑signal gradients, orbital ephemeris data,
relativistic corrections, and constraint‑bounded trilateration. GPS is a
machine‑facing geometry of spherical intersection.
