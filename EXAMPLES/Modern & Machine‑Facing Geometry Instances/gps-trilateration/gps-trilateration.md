# GPS Trilateration — Summary (DSLO v0.7)

GPS determines position by intersecting distance spheres from multiple
satellites. Each satellite sends a timestamp; the receiver measures delay,
converts it to distance, and solves the spherical intersection.

**Key Properties**
- Distance spheres  
- Multi‑satellite intersection  
- Timing‑signal gradients  
- Relativistic corrections  

**DSLO Interpretation**
- Operators: gradient, intersection, routing  
- Invariants: spherical coherence, timing stability  
- Manifolds: distance‑sphere, intersection, ephemeris  
- Dynamics: drift, collapse/restoration
