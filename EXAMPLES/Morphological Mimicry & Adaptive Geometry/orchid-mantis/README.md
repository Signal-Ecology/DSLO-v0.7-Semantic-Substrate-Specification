## Overview

that aligns with orchid petals. Its geometry is not merely visual: limb
curvature, petal-like lobes, color gradients, and surface texture combine to
produce a multi-scale floral manifold.

This mimicry is developmental rather than real-time. The mantis grows into a
geometry that matches petal curvature, color distribution, and boundary
structure. It is a static but highly optimized deception system.
