# Instance: L-Systems 
Version: DSLO v0.7  
Layer: Geometry / Natural Invariants  
Type: Example Instance (Non‑Glossary)

## Overview
Lindenmayer systems (L‑systems) are recursive rewriting systems that generate
complex geometric structures from simple production rules. Originally developed
to model plant growth, L‑systems demonstrate how natural forms emerge from
local, rule‑bounded recursion. Their geometry is substrate‑neutral: any medium
capable of symbolic rewriting can produce the same structures.

L‑systems illustrate DSLO’s core principle that recursive operators generate
stable manifolds, coherent branching, and fractal‑like geometry across scales.

## Key Properties

### **Invariant Behavior**
- Rule‑bounded recursive rewriting  
- Stable branching patterns  
- Self‑similar geometry across iterations  
- Deterministic growth under fixed production rules  

### **Geometry**
- Fractal branching structures  
- Recursive curves (e.g., Koch, Hilbert, Peano)  
- Plant‑like morphogenesis  
- Multi‑scale coherence  

### **Signal Ecology**
- Synthetic symbolic signals (rewriting rules)  
- Biological analogs (growth hormones, branching cues)  
- Environmental modulation signals (light, space)  

### **Substrate Alignment**
L‑systems belong in DSLO’s geometry layer because they demonstrate how recursive
operators generate coherent geometry independent of substrate. They are not
glossary terms; they are example instances showing DSLO invariants such as
recursion, drift, branching coherence, and manifold formation.
