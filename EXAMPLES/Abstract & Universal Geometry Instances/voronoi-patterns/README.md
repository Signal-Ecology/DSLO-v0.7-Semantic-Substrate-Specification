# Instance: Voronoi Patterns 
Version: DSLO v0.7  
Layer: Geometry / Natural Invariants  
Type: Example Instance (Non‑Glossary)

## Overview
Voronoi patterns partition space into regions based on proximity to a set of
seed points. Each region contains all points closer to its seed than to any
other. This geometry emerges naturally in biological tissues, crystal growth,
urban planning, and machine systems where distributed agents compete for space.

Voronoi geometry demonstrates how local proximity rules generate global spatial
structure. The pattern is substrate‑neutral: any system with distributed points
and distance metrics will produce similar partitions.

## Key Properties

### **Invariant Behavior**
- Proximity‑bounded spatial partitioning  
- Stable region boundaries  
- Deterministic geometry under fixed seed positions  
- Distributed spatial coherence  

### **Geometry**
- Convex polygonal regions

- Multi‑scale tessellation  
- Natural partition manifolds  

### **Signal Ecology**
- Spatial competition signals

### **Substrate Alignment**
Voronoi patterns belong in DSLO’s geometry layer because they express natural
invariants—proximity partitioning, spatial coherence, and distributed geometry—
that arise from local interactions. They are not glossary terms; they are
example geometry instances illustrating DSLO invariants such as drift,
coherence, and manifold formation.
