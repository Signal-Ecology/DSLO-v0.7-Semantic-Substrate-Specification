# Fractal Coastlines — Summary (DSLO v0.7)

Fractal coastlines show scale‑invariant roughness: the measured length increases
as measurement resolution increases. This reflects natural recursive geometry
driven by erosion, wave impact, and sediment flow.

**Key Properties**
- Scale‑invariant roughness  
- Self‑similar geometry  
- Stable fractal dimension  
- Recursive boundary structure  

**DSLO Interpretation**
- Operators: recursive growth, propagation, boundary curvature  
- Invariants: fractal roughness, stable dimension  
- Manifolds: coastline boundary, indentation manifold  
- Dynamics: erosion drift, storm collapse, sediment restoration
