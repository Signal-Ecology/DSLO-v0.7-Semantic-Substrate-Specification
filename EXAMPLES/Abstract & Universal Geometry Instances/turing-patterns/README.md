# Instance: Turing Patterns  
Version: DSLO v0.7  
Layer: Geometry / Natural Invariants 
Type: Example Instance (Non‑Glossary)

## Overview
Turing patterns arise from reaction–diffusion systems in which two interacting
chemical species diffuse at different rates. Under specific parameter regimes,
the system spontaneously forms stable spatial patterns such as stripes, spots,
labyrinths, and spirals. These patterns emerge without centralized control,
demonstrating how distributed chemical signals generate coherent geometry.

Turing patterns illustrate DSLO’s principle that geometry can arise from
competitive and cooperative signal interactions. Their invariants are
substrate‑neutral: any medium supporting reaction–diffusion dynamics can produce
similar forms.
