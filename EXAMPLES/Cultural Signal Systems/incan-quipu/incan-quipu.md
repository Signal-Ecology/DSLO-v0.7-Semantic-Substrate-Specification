# Incan Quipu — Summary (DSLO v0.7)

Incan Quipu encode information using knots, branching cords, spacing, and color.
They form a physical data structure where knot type, position, and hierarchy
represent numbers and categories.

**Key Properties**
- Knot‑based encoding  
- Hierarchical branching  
- Positional numeric structure  
- Color‑coded categories  

**DSLO Interpretation**
- Operators: branching, knot formation, categorical encoding  
- Invariants: knot families, positional encoding  
- Manifolds: cord, knot, branching  
- Dynamics: drift, collapse/restoration  

This instance is part of the DSLO Natural Geometry Registry.
