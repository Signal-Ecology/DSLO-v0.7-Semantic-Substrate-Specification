# Polynesian Stick Charts — Summary (DSLO v0.7)

Polynesian stick charts encode ocean swells, wave interactions, and island
positions using curved sticks, intersections, and shell markers. They are
physical navigational geometries built from environmental signals.

**Key Properties**
- Curved swell lines  
- Intersection patterns  
- Island node markers  
- Distributed environmental encoding  

**DSLO Interpretation**
- Operators: swell propagation, landmark encoding, distributed cognition  
- Invariants: curvature families, intersection stability  
- Manifolds: swell, intersection, island-node  
- Dynamics: drift, collapse/restoration  

This instance is part of the DSLO Natural Geometry Registry.
