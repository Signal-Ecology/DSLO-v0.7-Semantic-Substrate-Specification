## Overview
Arabic calligraphy flow is a geometric system in which linguistic meaning,
aesthetic rhythm, and spatial curvature converge into a unified signal ecology.
The geometry emerges from stroke dynamics, pen angle, pressure modulation, and
canonical proportional systems (e.g., the dot unit). Flow is not decorative but
structural: each stroke encodes direction, curvature, and rhythm.

Calligraphic flow demonstrates how cultural systems generate stable geometry
through embodied practice. Its invariants arise from repeated execution,
canonical training, and distributed cultural transmission across centuries.
