# Ant Foraging Network — Summary (DSLO v0.7)

Ant foraging networks form when ants deposit pheromones, follow gradients, and
reinforce successful trails. This creates branching, merging, and optimized paths
without centralized control.

**Key Properties**
- Pheromone gradients  
- Branching and merging  
- Drift‑optimization cycles  
- Dynamic trail geometry  

**DSLO Interpretation**
- Operators: gradient formation, branching, optimization  
- Invariants: gradient coherence, branching stability  
- Manifolds: trail, branching, gradient  
- Dynamics: drift, collapse/restoration  

This instance is part of the DSLO Natural Geometry Registry.
