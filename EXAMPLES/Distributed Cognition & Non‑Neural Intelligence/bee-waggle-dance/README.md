## Overview

foragers encode direction, distance, and resource quality through body angle,
waggle duration, and vibrational amplitude. The dance is performed on the
vertical comb surface, using the sun’s azimuth as a reference frame. Other bees
decode this geometry through tactile and vibrational signals.

The waggle dance demonstrates how non‑neural collective systems generate stable
geometry through embodied signaling. Its invariants arise from angle‑duration
coupling, vibrational coherence, and drift‑optimization cycles that persist
