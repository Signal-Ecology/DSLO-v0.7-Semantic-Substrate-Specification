# Instance: Mycelium Network  
Version: DSLO v0.7  
Layer: Geometry / Distributed Cognition & Non‑Neural Intelligence  
Type: Example Instance (Non‑Glossary)

## Overview
Mycelial networks are distributed biological routing systems formed by fungal
hyphae exploring, branching, merging, and reinforcing pathways based on nutrient
gradients and environmental feedback. No central controller exists; instead,
each hyphal tip acts as an autonomous agent responding to local chemical and
mechanical signals.

The network’s geometry emerges from millions of micro‑decisions: growth toward
nutrients, avoidance of toxins, reinforcement of efficient routes, and pruning
of unproductive branches. Mycelium is a substrate‑level optimization engine.

- Gradient‑driven exploration

- Adaptive pruning of inefficient routes  
- Distributed nutrient‑routing stability

### **Signal Ecology**

a geometry instance illustrating DSLO invariants such as drift, collapse,
